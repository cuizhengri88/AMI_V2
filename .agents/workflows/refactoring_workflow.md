이 워크플로우는 거대 페이지 분리, Rust 모듈화, 보안 설정을 안전하게 수행하기 위한 절차입니다.

### 🛡️ 1. 보안 및 기초 환경 설정 (P0)
1. 루트 디렉토리에 `.env` 파일을 생성하고 DB 접속 정보를 이동합니다.
2. `tsconfig.json`을 수정하여 불필요한 경로를 제외합니다.

### 🦀 2. Rust 모듈 정규화 (P1)
1. `src-tauri/src/app/mod.rs`에서 `include!` 구문을 `pub mod` 구문으로 변경합니다.
2. 각 파일의 함수에 `pub` 키워드를 추가하여 가시성을 확보합니다.

### 🧩 3. 대형 페이지 리팩터링 (P1)
1. `ReservationCalendarPage.tsx`에서 고정된 상수를 `types.ts`로 추출합니다.
2. API 호출 로직을 전용 Hook(`.ts`)으로 추출합니다.
3. UI 조각들을 50~100줄 내외의 하위 컴포넌트로 분리합니다.

### ⚡ 4. 라우트 최적화 (P2)
1. `App.tsx`에서 `import`를 `React.lazy`로 변환합니다.
2. `Suspense`를 사용하여 로딩 UI를 추가합니다.
